Simple Registration Form README

Overview:

This project consists of a simple Registration Form built using HTML, CSS, and JavaScript.
The primary function of the form is to collect user registration information and validate 
that the "Password" and "Confirm Password" fields match before submission.

Features
User-friendly interface for registration.
Password and Confirm Password validation.
Responsive design that works on various screen sizes.

Technologies Used:

1. HTML: For the structure of the registration form.
2. CSS: For styling and layout.
3. JavaScript: For form validation and interactivity.
